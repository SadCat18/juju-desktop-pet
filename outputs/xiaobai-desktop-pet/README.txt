啾啾桌宠

双击“启动啾啾桌宠.cmd”即可启动。

这个入口启动的是 `spine-poc\desktop-host` 中的新版 Spine 2D + GPU 原生宿主。目录里的历史 PowerShell 实现已移到 `legacy`，当前不要直接打开其中的脚本或精灵表。

操作：
- 鼠标移到啾啾上：打开圆角互动面板
- 喂食、喝水、摸摸、玩耍、清洁：点击面板按钮
- 喂食：显示饭碗并播放低头吃饭、抬头的过程
- 喝水：显示水碗并播放低头喝水、抬头的过程
- 玩耍：啾啾会和一只小球互动
- 无操作一段时间：啾啾会自己打盹、玩耍或挥手
- 拖动优化：跟随系统合成渲染帧，180Hz 显示器上可获得更顺滑的拖动
- 刷新设置：在互动面板点击“刷新设置”，可选择节能 60Hz、中等 180Hz、流畅 300Hz；实际帧率受显示器和系统合成器上限影响
- 基础设置：可开关自动行为并调整间隔，可调宠物大小和透明度，可记住位置，并在全屏应用时暂停自动行为
- 拖动啾啾：按住左键移动
- 握手：单击啾啾
- 跳跳：双击啾啾
- 查看状态：点击面板中的“查看状态”
- 退出：右键啾啾选择“退出啾啾”，或按 Esc

这是 Windows 原生 WPF 桌宠，不需要安装 Electron 或其他依赖。
状态会自动保存在 pet-state.json，下次启动会继续保留。

当前初始造型为无背带、无衣服的真实白狗；装备和衣服功能留到下个版本。

如果要打开浏览器体验版，请运行：
  ..\..\spine-poc\启动Spine原型.cmd
它会打开完整网页界面；桌面宠物请始终使用本目录的“启动啾啾桌宠.cmd”。

当前版本请通过启动脚本使用桌面宿主；不要从 `legacy` 目录直接启动历史 PowerShell 版本。
