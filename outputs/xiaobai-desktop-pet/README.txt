啾啾桌宠 Windows 发行包

双击“启动啾啾桌宠.cmd”即可启动当前 WPF + WebView2 宿主。该入口复用仓库中的正式宿主链路；不要直接运行 legacy 目录中的历史 PowerShell 宿主或旧资源。

当前功能：
- 左键未移动单击：摸摸头；300ms 内快速二击：跳跳；按住移动超过阈值：拖动窗口。
- 右键宠物：打开 HTML 快捷菜单，可喂食、喝水、梳毛、休息或退出。
- 点击照顾面板：可进行握手、玩球、睡觉、喂食、喝水、清洁和等待。
- 面板显示五维状态、食物/水库存、每日补给、动作消耗、成长与成就。
- 状态保存在 `%LOCALAPPDATA%\JiuJiuSpinePet\pet-state.json`，也可在面板导出/导入 JSON 存档。
- 支持自动行为开关、节能/标准/流畅动画更新档位、桌宠大小、静音/音量和默认关闭的本地装饰。
- 全屏/演示或锁屏时，宿主会取消置顶并暂停自动行为；解锁后按本地时段问候。
- 宿主托盘使用宠物图标，并在低饥饿/口渴时显示通知气泡；窗口位置会按所在显示器工作区保存和校正。

资源与说明：
- 当前初始造型为无背带、无衣服的真实白狗。
- 当前 Spine 资源实际使用单 root 骨骼和整帧槽位；喂食/喝水使用照片帧双槽过渡。完整分层 rig/网格需要后续真实 Spine 资产，不会伪称已启用。
- 浏览器体验版请运行 `..\..\spine-poc\启动Spine原型.cmd`；Android 版请使用 `android-pet` 工程。
- 桌面宿主依赖 Windows、.NET Framework 4.x、WebView2 runtime 和本包内的 WebView2 程序集，不需要 Electron。

退出方式：右键快捷菜单选择“退出啾啾”，或点击托盘菜单中的“退出啾啾”。
